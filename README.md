# Conecta+ | Documentação

Repositório destinado à documentação do projeto acadêmico **Conecta+**.

Aqui estão reunidos os documentos produzidos durante o desenvolvimento do projeto, como requisitos, diagramas, modelos e documentação dos incrementos.

## Estrutura

```text
DOCUMENTATION/
├── 1 - PropostaInicial/
└── 2 - Incremento1/
```

### 1 - Proposta Inicial

Contém os documentos relacionados à definição inicial do projeto, como objetivos, requisitos, identidade visual e planejamento.

### 2 - Incremento 1

Contém a documentação referente ao primeiro incremento desenvolvido no projeto.
